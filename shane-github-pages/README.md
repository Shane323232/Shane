# SHANE // Access Terminal

GitHub Pages-ready version of the SHANE website.

## Publish with GitHub Pages

1. Create a GitHub repository. For a personal site, name it `YOUR-USERNAME.github.io`; GitHub also supports project sites in normal repositories.
2. Upload **all files in this folder** to the repository. Keep `index.html` at the repository root.
3. In **Settings → Pages**, choose the branch containing these files as the publishing source.
4. If this is a user site, the address will be `https://YOUR-USERNAME.github.io/`. A project site uses `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
5. Replace `YOUR-USERNAME` in `robots.txt` and `sitemap.xml` with your actual GitHub username. If using a project site, change the sitemap URL to the full project-site URL.
6. After the site is live, submit the URL to Google Search Console and Bing Webmaster Tools to request indexing.

## Files

- `index.html` — the complete website
- `robots.txt` — tells crawlers they may crawl the site and points to the sitemap
- `sitemap.xml` — sitemap for search engines
- `404.html` — custom not-found page
- `.nojekyll` — keeps GitHub Pages from applying Jekyll processing to the static files
